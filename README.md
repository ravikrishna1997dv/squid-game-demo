# Squid Gamerz — Investor-Facing Website Prototype

A responsive, interactive static website for the proposed Squid Gamerz travelling live-game event concept.

## Concept details carried into this prototype

- Working brand: Squid Gamerz / Squid Gamerzz
- Proposed format: 24-hour event, 3 PM to 3 PM
- Target capacity: 456 players
- Proposed ticket price: ₹2,000 per player
- Proposed winner prize: ₹1,00,000
- Proposed inclusions: costumes, overnight stay/arrangements, food and drinking water
- Working game list: Red Light, Green Light; Mini 4; Dalgona-style precision; Mingle; a night surprise round with the working name “Duckje”
- Expansion idea: a relocatable pop-up format moving to another city approximately every 3–4 months
- Audience and acquisition ideas: Indian youth and families, colleges, campus ambassadors, creators, communities, and potential corporate/private events
- Longer-term idea: test a three-city pilot rollout after the first event model is validated

## Included features

- Premium responsive landing page and original geometric visual identity
- Clickable game-round selector
- Editable event unit-economics calculator
- Investor/partner section
- Operations, safety, transparency and brand/IP trust section
- Mobile navigation
- Static hosting compatible: no build step, Node.js, or dependencies required

## Run locally

Open `index.html` in a modern browser.

Optional local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy with GitHub Pages

1. Create a repository, e.g. `squid-gamerz`.
2. Upload the contents of this folder into the repository root (`index.html`, `styles.css`, `app.js`, `README.md`).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
5. Wait for deployment. GitHub will display the published URL in the Pages settings. It will usually resemble `https://YOUR-USERNAME.github.io/squid-gamerz/`.

## Before sharing with investors or selling tickets

This is a concept website, not proof of a launched or funded business. Replace the example email `hello@squidgamerz.example`, add the founder's real contact details, and distinguish confirmed facts from proposals. Do not claim venue bookings, sponsor commitments, insurance, permits, paid attendance, or profits unless documented.

The calculator is deliberately illustrative. The example cost input is a placeholder, not a quote or full event budget. Validate venue rental, modular construction, staffing, security, medical cover, accessibility, sanitation, food, water, accommodation, insurance, production, transport, taxes, payment fees, refunds, marketing and contingency with actual quotes and professionals.

## Legal, brand and safety note

The concept references games associated with existing entertainment IP. This website uses original geometric styling and does not include official series logos, characters, imagery or claims of affiliation. Before commercial use, obtain qualified legal advice on brand naming, trademarks, game mechanics, marketing, prize/competition rules, local event permissions, labour, food safety, privacy, child safeguarding if minors are admitted, insurance and safety. Use original or properly licensed names, costumes and game designs.

All proposed games must be independently risk-assessed, accessible where practicable, supervised, non-contact where possible, and supported by emergency plans, trained marshals, first aid, evacuation procedures, rest and hydration. The overnight format must be operationally and legally reviewed before it is announced.
